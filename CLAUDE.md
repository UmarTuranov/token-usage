# token-usage

Локальный дашборд расхода токенов Claude Code. Без зависимостей: Python stdlib + ванильный JS/SVG.

- `server.py` — парсит `~/.claude/projects/**/*.jsonl`, отдаёт `/api/data` и статику из `public/`. Кэш по mtime файлов. После правок в `server.py` сервер нужно перезапустить.
- `public/app.js` — вся агрегация на клиенте (фильтры, графики, таблицы, карточка сессии). Графики — рукописный SVG, без библиотек.
- `public/style.css` — токены цветов в `:root`, тёмная тема через `prefers-color-scheme`.
- `prices.json` — тарифы для оценки стоимости.

Стиль: сдержанный, «отчётный» — тонкие линии, моноширинные цифры, без градиентов, теней, эмодзи и карточек-пузырей. Интерфейс на русском.

Запуск: `python3 server.py` → http://127.0.0.1:8765
